# FlowLite UI spec (clean-room rebuild of Wispr Flow 1.6.1102's hub, fully offline)

Source of truth: live screenshots of the user's Wispr Flow (not included in this repository; they contain private dictations and were used only for layout), plus a static inventory of the Wispr bundle. Recreate layout, spacing, colors, states and behaviour with **original code and copy**. Never copy Wispr's code, images, sounds, logos or long marketing text; short labels (≤6 words: "Add new", "Personal messages", "Launch app at login") are fine.

Reference screenshots (2x scale of 1352×854 CSS px, so divide pixel positions by 1.25 for CSS px):
(kept locally, not in this repository)
hub.png (Home), insights.png, dictionary.png, dict_add.png, snippets.png, style.png, style_cleanup.png, transforms.png, notetaker.png (not built), settings.png (General), settings_system.png, settings_privacy.png, flowlite_shell.png (our shell), flowbar_states.png (our pill).

## Stack and shared code (already written — build on it, don't fork it)
- PySide6 6.12, Python 3.11, run with `.venv\Scripts\python`. Windows only.
- `flowlite/qtui/theme.py`: palette (`SAND`, `VAST`, `TEAL`, `BACKGROUND` #fcfcfb canvas, `CHROME` #f5f4f0, `SECONDARY` #eeebe3 borders, `TERTIARY` #f5f4f0 grouped cards, `CARD` #fff, `LIST_BG`, `FOREGROUND` #1a1a1a, `FOREGROUND_TERTIARY` #71716e, `ORANGE` #ffa946, `PURPLE_BORDER`, `PURPLE_TINT`, `RECORDING_FG`), fonts `ui_font(px, weight)` (Figtree) and `display_font(px)` (EB Garamond serif, used for hero headlines, settings pane titles, "My Transforms", cleanup level names, big numbers), `stylesheet()` defines object names `Primary`, `Secondary`, `Ghost`, `Tab`, `PageTitle`, `SectionLabel`, `Muted`.
- `flowlite/qtui/icons.py`: `icon(name, size, color, stroke)`, `pixmap(...)`. Names: mic insights dictionary snippets style transforms scratchpad settings help panel user bell minimize maximize close search sort refresh copy play undo more trash plus arrow chevron info sliders laptop shield cpu file bot infinity chat mail work monitor keyboard globe download lock check stop sparkle logo. Add new Lucide-style paths there if needed (keep the ISC note).
- `flowlite/qtui/widgets.py`: `label(text, px, weight, color, wrap)`, `display_label(html, px, color)`, `section_label(text)`, `button(text, kind, on_click)`, `shadow(w)`, `hline()`, `Toggle(checked)` (52×30 switch, `toggled` signal), `Card(bg, radius, border, padding)` (`.lay`), `ListCard()` (`.add(row)`, `.clear()`), `HoverRow()` (`.lay` QHBoxLayout, `.set_actions(widget)` shows on hover, `clicked`), `TabBar(tabs, badges={"Auto cleanup":"Beta"})` (`changed(int)`, `.add_tool(w)`), `KeyChips("win+alt+1")`, `key_label()`, `Hero(title_html, body_html, palette in dusk|ember|lagoon|plum)` (`.add_button(text, cb, light)`, `.add_chip(text, cb, italic)`, `.extra` layout, `dismissed` signal), `IconButton(name, tooltip, size, box)`, `PageHeader(title, beta)` (`.add_right(w)`), `SearchField(placeholder)`, `EmptyState(icon, title, body)`, `SettingsGroup()` (`.add(row)`), `SettingRow(title, description_html, control)` (`.set_description`), `change_button(cb, text="Change")`, `Modal(host, width, height)` (`.body` QVBoxLayout, `.open()`, `.close_modal()`, `closed`), `confirm(host, title, body, confirm_text, on_confirm, danger)`, `Toast` (use `ctx.bus.toast.emit("Saved")`).
- `flowlite/qtui/context.py`: `AppContext` with `settings` (store.Settings dataclass; call `ctx.save_settings()` after changes), `db` (store.Database: `query(sql, params)->list[dict]`, `insert(table, **row)`, `update(table, id, **fields)`, `delete(table, id)`, `execute`), `history` (store.History: `recent(limit, offset, search)`, `get(id)`, `delete(id)`, `stats()`, `words_per_day()`, `usage_by_category()`, `last_text()`), `dictionary` (dictionary.Dictionary: `entries(snippets, search, sort)` sort in newest|oldest|alpha|starred, `add(phrase, replacement, snippet, source)`, `update(id, **fields)`, `remove(id)`, `star(id, bool)`), `bus` (signals `history_changed`, `dictionary_changed`, `notes_changed`, `settings_changed`, `toast(str)`, `navigate(str)`, `open_settings(str)`), `formatter` (formatter.Formatter: `_chat(messages, num_predict)` talks to local Ollama; may be unavailable → catch OSError), `controller`, `recorder`, `extras` (dict of callables the app provides — see each page).
- Database tables (`flowlite/store.py` SCHEMA): `history(id, ts, mode, app, title, category "apptype/stylecat", language, asr_text, final_text, edited_text, words, audio_ms, speech_ms, tail_ms, llm_ms, total_ms, used_llm, replacements, status, source, audio WAV blob)`, `dictionary(id, phrase, replacement, is_snippet, source manual|learned, starred, used, created, modified)`, `notes(id, title, content, created, modified, pinned)`, `transforms(id, name, description, prompt, shortcut_slot transform_1|transform_2|NULL, builtin, position)`.
- A page is a `QWidget` subclass with `__init__(self, ctx)`, optional class attribute `MAX_WIDTH` (default 1000; Wispr content column is ~800 css px for Dictionary/Snippets/Style/Transforms, ~1045 for Home/Insights), and optional `refresh()` (called each time the page is shown). The shell (`flowlite/qtui/shell.py`) wraps it in a scroll area with 40 px side / 44 px top padding. Modals use `self.window()` as host.
- Everything must work fully offline. Do not add network calls or new pip dependencies (numpy, sounddevice, PySide6 are available).

## Global look
Warm off-white. Page title 30 px semibold Figtree top-left of the content column, primary action ("Add new", black, radius 8) top-right. Tabs underline style with a hairline below and small icon tools (search, sort, refresh) right-aligned in the tab row. Hero banners: 16 px radius, painted gradient, serif 40 px headline with an *italic* accent word, white 16 px body, light pill buttons. Lists: rounded #fcfcfb card with #eeebe3 border and hairline separators, rows ~66 px, 16 px text, hover tint sand-200 + action icons on the right. Spacing between sections ~28–32 px. Use plain-language, original copy.

## Pages

### Home (`pages/home.py`, `HomePage`, MAX_WIDTH 1100)
- Header "Welcome back, {settings.first_name}" (24–30 px semibold).
- Two-column top row: left a Hero (palette "lagoon") with a rotating tip (e.g. how to use hands-free: double-tap Ctrl+Win; snippets; Command Mode) and a button that navigates (`ctx.bus.navigate.emit("snippets")`); dismissible. Right a stats card (bg TERTIARY, radius 16, ~310 px wide): three lines "9,968 total words", "126 wpm", "1 day streak" — number in serif 34 px, unit in 17 px Figtree; clicking navigates to insights. Below the stats, in the same card separated by a hairline: a small card linking to Insights ("Your voice profile" style teaser is fine, original copy).
- History: section label = date ("OCTOBER 10, 2026", Today/Yesterday allowed) uppercase 13 px letter-spaced, search icon on the right of the first label that toggles a SearchField. Grouped list cards per day; each row: time ("4:34pm", muted 15 px, fixed 110 px column) + text (16 px, wraps, supports RTL Hebrew automatically). Hover actions on a row (right side, icons 18 px): play audio (only if has_audio; play the WAV blob with sounddevice, stop on second click), copy (clipboard via QGuiApplication.clipboard(); toast "Copied"), undo AI edit (toggle showing asr_text vs final_text, tooltip "Show original"), and a "more" menu (QMenu: Copy original transcript, Retry transcript → `ctx.extras["retry"](history_id)` which returns new text or None — run in a thread and refresh, Delete → confirm). Load 100 rows initially, "Load more" at the bottom. Empty state "No dictations yet" + hint "Hold Ctrl + Win anywhere and start talking".
- Refresh on `ctx.bus.history_changed`.

### Insights (`pages/insights.py`, `InsightsPage`, MAX_WIDTH 1100)
- Title "Insights", TabBar ["Your usage", "Your voice"].
- Your usage: row of 3 cards (bg TERTIARY, radius 16): (1) WPM: big number 34 px + "WORDS PER MINUTE" label 13 px letter-spaced + a semicircle gauge (teal dark #1a5c5c arc, track #eeebe3, 10 px stroke) with "Top x%" from Wispr's tagline thresholds (<40 keep going; <75 faster than 90% of typists; <85 95%; <95 97%; <105 top 5%; <125 top 3%; <135 top 2%; else top 1% — phrase originally). (2) Fixes: big number = dictionary_fixes + words_corrected, label "FIXES MADE BY FLOWLITE", hairline, two lines "N words corrected" / "N dictionary fixes" with info icons (tooltips). (3) Total words: big number, label "TOTAL WORDS DICTATED", pill top-right "↗ x% this month" (compare last 30 days vs previous 30), hairline, a fun comparison line (e.g. "That's about N novels' worth" — original wording; pick from tweet=30, email=120, essay=1000, novel=90000 words), and a teal bar.
- Second row: "Desktop usage" card (left, ~45%): serif-ish 30 px title, "TOTAL APPS USED | N" right; rows with icon (bot for AI, file for document, infinity for other, chat for messaging/personal, mail for email, work for work messages) + teal bar with percentage inside (darkest for largest) + "N AI PROMPTS / DOCUMENTS / OTHER TASKS / PERSONAL MESSAGES / EMAILS / WORK MESSAGES" uppercase label. Data from `history.usage_by_category()` (keys: ai, document, other, messaging, email, terminal) and categories "apptype/stylecat" (stylecat personal/work/email/other) — compute personal vs work messages from the stylecat part via `ctx.db.query`.
- "N day streak" card (right, ~55%): title serif 30 px, "LONGEST STREAK | N DAYS" right, GitHub-style heatmap of the last ~20 weeks: rows Sun..Sat labels 12 px, month labels on top (Jun, Jul …), cells 22×22 px rounded 3, gap 8, colors by words/day: 0 → #c5c0b3 (or lighter #e8e4dc for future days), low → #ceedea, mid → #84cdc1, high → #369489, top → #1a5c5c; legend "More ■■■■ Less"; < > arrows to page months.
- Your voice: local, computed from history text: most used words (excluding stopwords), most corrected words (from dictionary source='learned'), peak hour of day, languages used (from history.language), average dictation length. Cards in the same style. Original copy.

### Dictionary (`pages/dictionary.py`, `DictionaryPage`, MAX_WIDTH 800)
- PageHeader "Dictionary" + "Add new" (Primary). TabBar ["All", "Personal", "Learned"] with tools: search (toggles SearchField), sort (QMenu: Newest first, Oldest first, Alphabetical (A-Z), Starred first), refresh.
- Hero (palette "ember", dismissible; remember dismissal in `settings` — add a field only if needed via a tiny json in DATA_DIR is fine): serif "FlowLite spells the way <i>you</i> do." + body explaining correct once / add manually, with bold phrase; buttons: "Add new word" (light) + up to 5 chips of existing words.
- List: rows show phrase; replacements as "phrase → replacement"; learned entries get an orange sparkle icon after the text; starred show a filled star. Hover actions: star toggle, edit (opens the same dialog), delete.
- "Add to vocabulary" modal (480 px): title 20 px semibold; row "Correct a misspelling" + info icon + Toggle (when on, show two fields: "Misspelling" and "Correct spelling" with an arrow); input "Add a new word"; buttons Cancel (Secondary) / "Add word" (Primary, disabled until text). Enter submits. Emit `bus.dictionary_changed`.
- Empty and no-results states.

### Snippets (same file, `SnippetsPage`, MAX_WIDTH 800)
- Same layout. Hero (palette "plum"): serif "The stuff <i>you</i> shouldn't have to re-type." + body; example rows of chips `"my email" → you@example.com` (italic quoted trigger chip, arrow, expansion chip) — use generic examples, then "Add new snippet".

### Style (`pages/style.py`, `StylePage`, MAX_WIDTH 800)
- Title "Style". TabBar ["Personal messages", "Work messages", "Email", "Other", "Auto cleanup"] with "Beta" badge on Auto cleanup.
- Category tabs: Hero (palette "lagoon", not closable, ~185 px tall) serif "This style applies in {personal messengers|work messengers|email|other apps}" + body "Style formatting currently applies to English dictation." + on the right a row of overlapping 50 px circles with app initials (e.g. WhatsApp, Telegram, Discord) drawn in brand-neutral colors (no logos) + a "+" circle.
- Three selectable cards in a row (Formal. / Casual / very casual), each ~300×435: title + subtitle 17 px ("Caps + Punctuation", "Caps + Less punctuation", "No Caps + Less punctuation"), then near the bottom a chat bubble (bg PURPLE_TINT #f7f2fb-ish, radius 12) with a sample message rendered in that style and a 64 px avatar circle overlapping the bubble's bottom-right (letter "J"; light pink for formal/casual, deep wine #7a1f3d for very casual). Selected card: 1.5 px border PURPLE_BORDER; others #eeebe3. Clicking sets `settings.styles[cat]` to formal|casual|very_casual and saves.

Four cards None / Light / Medium / High (Wispr shows 3 at a time; 4 in a 2×2 or a row of 4 at ~190 px wide is fine): level name in serif 34 px, description 16 px muted, sample text bubble (italic 14 px, PURPLE_TINT) at the bottom showing that level's result for one shared example sentence. ### Transforms (`pages/transforms.py`, `TransformsPage`, MAX_WIDTH 800)
- PageHeader "Transforms" with Beta tag. Right side: KeyChips of `settings.shortcuts["transform_1"]` explanation pill ("Win Alt 1 to polish selected text").
- Hero (palette "ember"): serif "Transform works anywhere you write" + body "Select text in any app and press a Transform shortcut to rewrite it locally." + buttons "Try it out" (opens a modal with a QPlainTextEdit sample + transform picker + "Run" that calls the engine and shows the result) and "How it works" (light=False link → modal explaining: select text, press shortcut, FlowLite copies the selection, rewrites it with the local model, pastes it back).
- Row "Auto apply after dictation" (16 px medium) + description "Run a transform on everything you dictate, automatically." + combobox of transform names + Toggle; stored in `settings.auto_transform` ("" when off).
- "My Transforms" serif 34 px + right "Reset to defaults" (Ghost with refresh icon) + "Create New" (Primary).
- Grid of cards (3 per row, ~315×200, white, radius 16, border #eeebe3): KeyChips for the shortcut slot (if any), name 17 px semibold, description muted. Last card "Create your own" with a "+" circle. Click a card → edit modal (name, description, prompt QPlainTextEdit, shortcut slot combobox: None / transform_1 / transform_2 showing the key text; delete button for non-builtin). Store in `transforms` table.
- Engine: create `flowlite/transforms_engine.py` with `run_transform(formatter, prompt, text) -> str` (system = the transform prompt + "Output only the rewritten text.", user = the text; `formatter._chat(messages, num_predict=2000)`; strip quotes) — used by the page and by the app's shortcut handler.

### Scratchpad (`pages/scratchpad.py`, `ScratchpadPage`, MAX_WIDTH 1100)
- PageHeader "Scratchpad" + Beta tag + "New note" (Primary). Left column (260 px): SearchField + list of notes (title + preview + relative time, pinned first, hover delete/pin). Right: editor card — title QLineEdit (no border, 22 px semibold) + QTextEdit (rich text, 16 px, no border, placeholder "Start typing, or hold Ctrl + Win and talk…"), small toolbar (bold, italic, bulleted list, checklist via "☐ ", copy all) and a status "Saved" muted. ### Settings (`flowlite/qtui/settings.py`, `SettingsModal`)
`SettingsModal(ctx, host_window, pane="general")` → a `widgets.Modal` 960×640 radius 12. Left rail 210 px bg TERTIARY with section label "SETTINGS" (12 px letter-spaced, muted) and items (icon 18 + text 16, 40 px tall, radius 8, active bg #eeebe3): General (sliders), System (laptop), Models (cpu), Experimental (sliders/zap), section "PRIVACY": Data and Privacy (shield). Footer "FlowLite v2.0 · offline" muted 13 px. Right: pane title in serif 34 px ("General"), then SettingsGroups.
- General: Shortcuts row ("Hold [Ctrl] + [Win] and speak." with inline bold keys) + Change → Shortcuts dialog; Microphone row (current device name or "Default microphone") + Change → mic dialog (list `sounddevice.query_devices()` inputs, radio-like rows, "Default" first, test level meter optional; set `settings.mic` (index as str) and `ctx.recorder.device`); Dictation Languages row ("English · Hebrew (עברית) · Russian (Русский)" or "Auto-detect (99 languages)") + Change → languages dialog (Auto-detect toggle, search field, checklist of ~40 Whisper languages with native names, "Selected" section on top, "Save and close"); App Language row with a combobox containing only "English".
- Shortcuts dialog (720 px): title "Change shortcuts", rows Push to talk / Hands-free mode (hint "or double-tap push to talk") / Command mode / Paste last transcript / Copy last transcript / Transform 1 / Transform 2 / Cancel — each with a key-capture field showing KeyChips; click → border #A88ED5 and text "Press keys…", capture the chord with keyPressEvent (Ctrl/Win(Meta)/Alt/Shift + one key, max 3 keys, require a modifier unless Esc/F-key), Esc cancels capture, validate (max 3 keys, needs modifier, not a reserved combo like ctrl+c/v/x/z/a/s, alt+tab, alt+f4, win+l/d/e/r, not used by another action); show errors inline red 13 px. Footer "Reset to default" (Ghost) + "Done" (Primary). On Done: save into `settings.shortcuts` (format "ctrl+win+space", key names: ctrl win alt shift space esc enter tab a-z 0-9 f1-f24) and call `ctx.extras["reload_shortcuts"]()`; toast "Shortcuts saved".
- System: groups "App settings" (Launch app at login → `ctx.extras["set_autostart"](bool)`, current from `ctx.extras["autostart_enabled"]()`; Show Flow Bar at all times → `settings.show_resting_bar`), "Sound" (Dictation and notification sounds → `sounds`; Mute all audio while dictating → `mute_media`), "Notifications" (Suggestions → `notify_suggestions`; Milestones → `notify_milestones`), "Extras" (Auto-add to dictionary → `learn_from_edits`; Smart formatting row with a "Change" button that navigates to Style → Auto cleanup (`bus.navigate.emit("style")`)). Group headings 17 px medium above each SettingsGroup.
- Models (FlowLite-specific): Speech model combobox (tiny, base, small, medium, large-v3-turbo; mark which are downloaded by checking `~/.cache/huggingface/hub/models--Systran--faster-whisper-{name}` or `models--mobiuslabsgmbh--faster-whisper-large-v3-turbo`; non-downloaded ones disabled with "(run setup to download)"); restart-required note. Formatting model combobox listing `ctx.extras["ollama_models"]()` (local 127.0.0.1 call). Status row showing "Ollama: running/not running".
- Experimental: Command Mode (`command_mode_enabled`), Press Enter command (`press_enter_command`, description "Say 'press enter' at the end to send"), All lowercase (`all_lowercase`), Type instead of paste (`insert_mode` paste|type), Keep microphone warm (`warm_mic`, restart).
- Data and Privacy: hero-ish group explaining "Everything stays on this computer" with a lock icon; Context awareness (`read_context`); Keep recordings (`save_audio`); Local data storage combobox (Store data locally / Auto-delete after 24 hours / Never store history) → `local_storage` with confirm dialog when picking a destructive option; "Import from Wispr Flow" row + button → `ctx.extras["import_wispr"]()` (returns summary dict {history, words, snippets}) run in a thread, toast result, emit history/dictionary changed; "Delete all history" (danger confirm) → `ctx.db.execute("delete from history")`; "Open data folder" → `os.startfile(store.DATA_DIR)`.
Settings changes save immediately (`ctx.save_settings()`), like Wispr.
